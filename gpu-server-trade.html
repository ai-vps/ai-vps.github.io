一、现货出货

1. GPU 显卡 & AI 整机

  • RTX 5090：涡轮卡（135mm）、风扇卡均有现货；可承接 8×5090 整机大单，另有期货可订——整机大单提前锁价锁量，避开每周一跳的行情
  • 4090：涡轮卡、4090-48G 拆新。48G 改装版跑大模型推理的性价比之选，预算有限的推理场景可以重点看
  • Hopper 系列：H200 原版 PCIe 单卡（深港现货）；H20 整机——合规需求场景的主力货
  • Ampere 系列：A100 40G/80G、A800-80G、H800-80G 整机现货；华硕 H800。训练老模型集群、二线算力租赁仍然刚需
  • 英伟达专业卡：Pro5000（32G/72G）、Pro6000 / Pro6000D（服务器版、工作站版）、A16 / A400 / A1000 / A2000 / 2000Ada / T4 / L20 / L40 / L40S 等。虚拟化桌面（A16）、视频转码（L40S）各有所长，拿不准用途直接问
  • 其他：DGX-Spark 整机、Jetson Orin NX 边缘计算盒子
期货与预订：8×5090 整机大单支持期货预订，交期与锁价以双方确认为准；批量订单可谈阶梯价。参考市场租赁价（8卡整机月租约1.5万-1.8万元），自购整机回本周期通常在两年上下，量大可以直接聊。

三、行话速查（买前必读）

行话意思对你意味着什么
DC23+/24+/25+生产批次码，数字代表年份（如25+即2025年及以后出厂）越新体质越好、剩余保修越长，价格也越贵；回收时25+的条子溢价明显
双标贴两个标签：原厂标 + 服务器品牌商标（HPE/华为/戴尔等）OEM 渠道正规货，能过品牌机保修体系，比白牌拆新贵一点但踏实
拆新从全新整机里拆出来单独卖的配件，通电时间极短或为零比盒装便宜、接近全新的品质；要求卖家提供通电时长截图
黑绷带三星高端 RDIMM 的行话俗称（散热片外观得名）96G/128G 高容量的主力货源，原箱未拆的最保值
WS未税美金离岸结算（香港仓交割）有美金收付需求的客户省掉税费环节；内地客户走含税人民币即可
期货现货没到、先锁价锁量等下一批到港行情上涨期锁价等于省钱，但要对供应商的履约能力有判断

四、验货要点

  1. 显卡：金手指磨损程度、PCB 有无飞线/维修痕、螺丝漆点是否完整；上机烤机 15 分钟看温度曲线和功耗墙是否正常，N 卡可用 GPU-Z 核对 BIOS 版本与显存品牌
  2. 内存条：标签料号与 SPD 信息比对（防打磨条），批次码核对生产日期；上机 memTest 跑满一轮；原箱货核对封条与装箱单
  3. 企业级 SSD：smartctl 查通电时长和总写入量（TBW），对照官方 DWPD 标称算剩余寿命；U.2 盘注意接口有没有插拔过度磨损
  4. 机械硬盘：MHDD/Victoria 扫坏道，注意听异响；企业级拆机盘看清年份标签与固件版本
  5. 整机：开机进系统看硬件清单是否与描述一致，GPU 机器重点压测多卡互联带宽

常见问题

Q：现在这个行情，该买还是该等？

说实话没人能精准抄底。但几个事实摆着：原厂 DDR5 产能优先供 CSP 大客户、长协签完散单更紧张；CFM 预计三季度合约还要涨 20% 左右；显卡这边 5090 已经连续几周上行。刚需就别赌回调，用期货锁价把风险锁住；非刚需可以分批建仓。

Q：8×5090 整机自己组和直接采购有什么区别？

自己组要操心兼容性（PCIe 5.0 主板、2000W 冗余电源、散热风道）、装机调试验证，周期两三周起步；整机采购当天提货、质保统一。量大的话期货整机还有阶梯价，综合成本反而更低。

Q：我手上有一批退役 A100 整机，怎么出手？

邮件发来配置清单（卡型/数量/使用年限/有无维修史），当天回报价。北京仓可上门验机，现款结算不打欠条。附带的服务器和硬盘也可以一起打包评估。

Q：香港仓交易的具体流程？

美金结算（WS 未税离岸价），确认订单后香港仓提货或安排物流，全程可第三方验货。适合有境外主体的公司；内地个人客户建议走深圳仓人民币流程，简单得多。
