6. 回收流程（四步走完）

  1. 报价：邮件/微信发清单（型号+数量+批次+成色描述），当天回参考价区间
  2. 验货：深圳/北京上门收货现场验，外地走顺丰保价到仓，验货视频全程可录
  3. 复检定价：以实测数据为准（通电时长、坏道扫描、烤机），与描述不符会重新报价，先沟通再动手
  4. 现款结算：对公转账/微信/支付宝均可，验完当场打款，不打欠条不压账期

买 H200/H20 前必须核对的四件事

  1. IB 网卡：H200 标配 8 张 400G IB 卡，单套含税成本约 7 万元。低价报价大概率不含 IB 卡，后期加装又是一笔钱，集群组网没 IB 根本无法多机联动
  2. 内存频率：标配是 32 根 64G DDR5-5600。报价里写 4800 的 = 商家后改低频条降本，整机带宽和稳定性都缩水
  3. H20 分清 96G / 141G：96G HBM3 是老款（带宽4TB/s），141G HBM3e 升级款贵 15%-22%，但单机可跑 671B 满血大模型，是当下推理刚需款。96G 库存渐少部分已停产
  4. A100 趁早：A100-80G 八卡购置价两月涨近七成到 117 万，自购设备基本全租出去了。老机型 GPU 不易坏、部件可换，保值属性强

顺带两个硬核数据：Akamai 实测 RTX PRO 6000 Blackwell 推理吞吐最高到 H100 的 1.63 倍（FP4 精度），"专业卡打不过数据中心卡"的老观念可以放放了；另外 8 卡机器满载超 3000W，4 卡以下风冷勉强，8 卡基本必上液冷——配机柜前先想清楚这个。

再加映：手上的模型到底要多大的卡？一张对照表

天天有人问"我跑个 XX 模型要什么卡"。粗算法子：FP16 推理显存 ≈ 参数量（B）× 2，再多留两三成给 KV cache 和运行开销。量化能省一半（INT8）甚至四分之三（INT4），但精度有损，生产环境慎用 INT4。对照着看：

模型规模FP16推理显存(约)省钱跑法生产环境推荐
7B-9B16G 左右T4 / 4090 量化随便跑5090 单卡，并发和吞吐都宽裕
14B30G 上下的样子单张 4090-48G 刚好Pro6000D / 双 4090-48G
32B70G 上下双 4090-48G 张量并行Pro6000D 单卡（84G 版本贴线，96G 稳）
70B150G 往上4×5090；INT4 一张 80G 卡能塞但别用于生产Pro6000D 原生 FP8 单卡可跑；多并发就 4 卡起
百亿级以上 / 671B 满血300G 起，上不封顶没有省钱的玩法，只有相对便宜的8×H200 / 8×H20-141G 整机起步
MoE 大杯（如满血 R1 671B）别被"活跃参数37B"骗了——全部权重都得驻留显存，FP8 就要 700G+INT4 压到 350-400G，8×H100 勉强塞下8×H200（1128G 显存）是标准答案

三个实战提醒：一，显存算得刚刚好的配置一定会在高峰期 OOM，留余量不是浪费；二，长上下文场景（32K 以上）KV cache 会吃掉大量显存——70B 模型 10 个并发跑 32K 上下文，光 KV cache 就要 800G，比模型本身还大，高并发务必按"参数量×精度字节×上下文×并发数"细算；三，训练比推理贵得多——全参微调大约每 10 亿参数要 16G 显存（7B 就得 100G+），多数团队实际需要的是 LoRA（7B 约 30-40G）甚至 QLoRA（7B 一张 24G 卡就能微调，70B 也只要一张 80G 卡）。拿不准把模型名和并发数发来，帮你对着现货配。

五、行话速查（买前必读）

行话意思对你意味着什么
DC23+/24+/25+生产批次码，数字代表年份（如25+即2025年及以后出厂）越新体质越好、剩余保修越长，价格也越贵；回收时25+的条子溢价明显
双标贴两个标签：原厂标 + 服务器品牌商标（HPE/华为/戴尔等）OEM 渠道正规货，能过品牌机保修体系，比白牌拆新贵一点但踏实
拆新从全新整机里拆出来单独卖的配件，通电时间极短或为零比盒装便宜、接近全新的品质；要求卖家提供通电时长截图

常见问题

Q：现在这个行情，该买还是该等？

说实话没人能精准抄底。但几个事实摆着：原厂 DDR5 产能优先供 CSP 大客户、长协签完散单更紧张；CFM 预计三季度合约还要涨 20% 左右；显卡这边 5090 已经连续几周上行。刚需就别赌回调，用期货锁价把风险锁住；非刚需可以分批建仓。

Q：8×5090 整机现在到底什么价？还能入手吗？

行情跑得快：单张涡轮卡渠道价约2.9万-3.5万元，整机采购价半个月内从47万被报到55万（中介渠道成交见过44.5万的）。能不能入看用途：自己用、按当前租金刚账能接受就买；指望买了放租回本的，按55万进价、月租1.3万算要三年半才回本，追高前想清楚。我们支持期货锁价锁量，交期以确认为准。

Q：H100 整机什么价？租一台一个月要多少？

采购端：全新八卡整机报价已到300万/台上下，数月前还不足200万，7月初华硕全新机三年质保报过274万。租赁端：主流月租7.8万-8.5万，西部闭口长协成交在7.5万-7.6万；零散单台流通性差，见过7.6万一年起签的让利盘。注意运营商对承租方风控越收越紧，部分集群已被锁定，租之前先把资质材料备齐。

Q：想本地部署 DeepSeek R1 满血版（671B），得备什么家当？

先泼冷水：满血版是 MoE 架构，虽然每个 token 只激活 37B 参数，但全部 671B 权重都得常驻显存——FP8 精度就要 700G 以上，标准答案是 8×H200（1128G 显存）整机，350 万起。INT4 量化能压到 350-400G，但精度有损。务实路线：绝大多数业务场景用 R1 蒸馏版（14B/32B）就够了，32B 的 INT4 版一张 4090-48G 就能跑，70B 蒸馏版 INT4 双 4090 可跑——先拿蒸馏版测业务，真不够再上满血，别反过来。

Q：8×5090 整机自己组和直接采购有什么区别？

自己组要操心兼容性（PCIe 5.0 主板、2000W 冗余电源、散热风道）、装机调试验证，周期两三周起步；整机采购当天提货、质保统一。量大的话期货整机还有阶梯价，综合成本反而更低。

Q：我手上有一批退役 A100 整机，怎么出手？

邮件发来配置清单（卡型/数量/使用年限/有无维修史），当天回报价。北京仓可上门验机，现款结算不打欠条。附带的服务器和硬盘也可以一起打包评估。

Q：香港仓交易的具体流程？

美金结算（WS 未税离岸价），确认订单后香港仓提货或安排物流，全程可第三方验货。适合有境外主体的公司；内地个人客户建议走深圳仓人民币流程，简单得多。

Q：听说高端算力市场假货源很多，怎么防？

这是真实现状。SMM 报道过 256 台 H200 的"批量低价长协"被质疑自循环倒手、128 台闭口合同疑为虚假信息。防三条：一看交付能力——敢约时间上门看货的才可信；二查合同闭环——违约罚则、押金规则写不清楚的直接pass；三警惕远低于行情的报价——350 万标配的 H200 卖你 280 万，不是骗局就是配置被动了手脚。

Q：H200 为什么这么贵，还会涨吗？

三层原因叠加：存量稀缺（流通量少，释放即被消化）、推理需求真实增长、灰色链路把运输资金风险计入了价格。有情景模型估算合理中枢在 250 万左右，但那是建立在 B300 放开供应的假设上。与其猜顶，不如盯三个信号：新卡交付节奏、月租有没有回落、期货现货价差是否收窄。这三个一起变的时候，行情才真的转向。

Q：个人能买吗，还是只做企业单？

都接，玩法不一样。个人买一两张卡走深圳仓现结最顺，当天拿货；企业采购整机、批量内存硬盘走对公合同+发票。实话实说：单张零售不是我们的主业，图的是量大价稳，但老客户带朋友来买卡从来不拒。

Q：期货订单的定金和违约条款怎么定？

常规做法：定金两到三成锁价锁量，尾款到港提货前结清。合同里写清双向违约——我们逾期交付按日赔付，客户弃单定金不退，谁毁约谁担责，没有霸王条款。签之前把交期宽限天数和赔付上限谈死，这轮涨价里因为供应商毁约闹扯皮的案例不少。

Q：跟电商平台比，找渠道货源图什么？

三样东西。一是料号透明——批次码、通电数据提前给，电商页面不会告诉你这些；二是量价阶梯——二十条内存和两百条内存是两个价，平台做不到；三是回收闭环——今天卖你的设备两年后退役我们还按行情收回去，资产有出口。小额零售确实电商更方便，量上来了渠道的优势就出来了。
