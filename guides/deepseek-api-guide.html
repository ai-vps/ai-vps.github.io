DeepSeek API免费额度怎么用？

DeepSeek是什么？

DeepSeek是国内头部AI公司，开源了多个大语言模型。它的API服务价格非常便宜，而且V4 Flash模型目前还有官方免费额度——不花一分钱就能用上顶级大模型。

第一步：注册DeepSeek账号

1. 打开 DeepSeek 官网 platform.deepseek.com

2. 点击"注册"，可以用手机号或邮箱注册

3. 填写手机号/邮箱，设置密码，完成验证

4. 注册完成后会赠送一定额度的免费余额（具体金额以官网为准）

第二步：获取API Key

1. 登录后进入控制台，找到"API Keys"或"密钥管理"

2. 点击"创建API Key"，给密钥起个名字（比如"my-app"）

3. 复制生成的API Key（格式类似 sk-xxxxxxxxxxxx）

注意：API Key只显示一次，务必保存好。如果丢失需要重新创建。

第三步：调用API

DeepSeek的API兼容OpenAI格式，如果你之前用过OpenAI的SDK，改个地址和Key就行：

import openai

client = openai.OpenAI(
    api_key="sk-your-deepseek-key",
    base_url="https://api.deepseek.com"
)

response = client.chat.completions.create(
    model="deepseek-chat",  # 或 deepseek-reasoner
    messages=[
        {"role": "user", "content": "你好，介绍一下你自己"}
    ]
)

print(response.choices[0].message.content)

也可以直接用curl调用：

curl https://api.deepseek.com/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-your-deepseek-key" \
  -d '{
    "model": "deepseek-chat",
    "messages": [{"role": "user", "content": "你好"}]
  }'
